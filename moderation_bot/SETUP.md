# 🚀 Настройка бота-модератора: пошаговая инструкция

От нуля до работающего бота — примерно 10 минут. Всё делается один раз.

**Что понадобится:** Python 3.10+, Telegram-аккаунт, права администратора в группе.

```
Шаг 1: токен у @BotFather  →  Шаг 2: отключить приватность  →  Шаг 3: установить
   ↓
Шаг 4: заполнить .env      →  Шаг 5: selftest + demo        →  Шаг 6: добавить в группу
   ↓
Шаг 7: ID группы (по желанию) → Шаг 8: /settings → Шаг 9: проверить на сообщении
```

---

## Шаг 1. Получите токен у @BotFather

1. Откройте переписку с [@BotFather](https://t.me/BotFather) (это официальный бот Telegram).
2. Отправьте `/newbot`.
3. Он спросит **имя** бота — любое, например `Модератор группы`.
4. Затем **username** — он должен заканчиваться на `bot`, например `my_group_moder_bot`.
5. В ответ придёт строка вида:

   ```
   Use this token to access the HTTP API:
   7712345678:AAH-xYzQ9_kLmNoPqRsTuVwXyZ012345678
   ```

   Это и есть **`BOT_TOKEN`**. Скопируйте его целиком (вместе с цифрами и двоеточием).

> 🔒 Токен — это пароль бота. Не публикуйте его, не пересылайте в чаты и не коммитьте в git.
> Если токен утёк — в @BotFather: `/revoke` → получить новый.

## Шаг 2. Отключите приватность бота (обязательно!)

По умолчанию бот видит **только** команды. Чтобы он видел обычные сообщения и мог их удалять,
нужно выключить privacy mode:

1. В @BotFather: `/setprivacy`
2. Выберите своего бота.
3. Нажмите **`Disable`**.

> ⚠️ Без этого шага фильтры не будут срабатывать на обычные сообщения — самая частая причина
> «бот не реагирует». Если после переключения бот всё ещё не видит сообщения — удалите его
> из группы и добавьте заново.

## Шаг 3. Установите бота

### Вариант А. Linux / macOS

```bash
cd moderation_bot                     # перейдите в каталог бота
python3 -m venv .venv                 # окружение
source .venv/bin/activate             # активировать
pip install -r requirements.txt       # зависимости (aiogram, aiosqlite, python-dotenv)
cp .env.example .env                  # создать файл настроек
```

### Вариант Б. Windows (PowerShell)

```powershell
cd moderation_bot
py -3 -m venv .venv
.venv\Scripts\Activate.ps1            # если ругается на политику: Set-ExecutionPolicy -Scope Process RemoteSigned
pip install -r requirements.txt
copy .env.example .env
```

### Вариант В. Одной командой (если есть `make`)

```bash
make setup      # зависимости + .env + автоматическая диагностика
```

## Шаг 4. Заполните `.env`

Откройте `.env` любым текстовым редактором (`nano .env`, `notepad .env`) и вставьте токен
в первую строку без кавычек и пробелов:

```ini
BOT_TOKEN=7712345678:AAH-xYzQ9_kLmNoPqRsTuVwXyZ012345678
TARGET_USERNAME=zaztagbot
BANNED_HASHTAG=#реклама
```

Минимум, который нужно изменить, — **`BOT_TOKEN`**. Остальные значения уже разумные:

| Переменная | По умолчанию | Когда менять |
|---|---|---|
| `BOT_TOKEN` | — | **Всегда**: вставить токен из шага 1 |
| `TARGET_USERNAME` | `zaztagbot` | если мешает другой бот/аккаунт — укажите его @username без `@` |
| `BANNED_HASHTAG` | `#реклама` | если реклама помечается другим хэштегом |
| `ALLOWED_CHAT_ID` | пусто | чтобы бот работал только в одной конкретной группе |
| `NOTIFY_ON_DELETE` | `true` | если не хотите подсказку «🗑 Удалено: …» в чате |
| `DB_PATH` | `data/moderation.sqlite3` | если нужно хранить базу в другом месте |

## Шаг 5. Проверьте готовность

```bash
python manage.py selftest          # проверка окружения, токена и связи с Telegram
python manage.py demo              # посмотреть, что бот сделает с примерами сообщений
```

`selftest` проверяет версию Python, зависимости, наличие `.env`, формат токена, доступ к базе,
связь с Telegram и наличие мешающего вебхука. Если что-то не так — он прямо пишет, что исправить:

```
🔍 Проверка готовности бота к запуску

✅ Python 3.11.9
✅ aiogram 3.31.0
✅ Файл настроек: /opt/moderation_bot/.env
✅ BOT_TOKEN задан (id бота из токена: 7712345678)
✅ Фильтр по пользователю: @zaztagbot
✅ Фильтр по хэштегу: #реклама
✅ База данных доступна: /opt/moderation_bot/data/moderation.sqlite3
✅ Telegram принял токен: @my_group_moder_bot (id=7712345678) → https://t.me/my_group_moder_bot
✅ Вебхук не установлен (long polling доступен), в очереди 0 апдейтов

🎉 Всё готово. Запуск: python -m bot
```

Если интернета нет — `python manage.py selftest --offline` (проверит всё, кроме Telegram).

`demo` показывает решения правил на типовых сообщениях, не отправляя ничего в чат:

```
✅ оставить                             | @friend          | Привет! Как дела?
🗑 УДАЛИТЬ — сообщение содержит #реклама | @spammer         | Срочная продажа курса #реклама
🗑 УДАЛИТЬ — сообщение от заблокированного | @zaztagbot (бот) | Подпишись на канал
```

## Шаг 6. Запустите бота

```bash
python -m bot
```

В логе должно появиться:

```
2026-01-01 12:00:00 | INFO     | bot.app | Бот запущен: @my_group_moder_bot (id=7712345678)
2026-01-01 12:00:00 | INFO     | bot.app | Фильтры: польз.=@zaztagbot | хэштег=#реклама | чат=все группы
```

Остановить — `Ctrl+C`. Окно терминала закрывать нельзя: пока процесс запущен, бот работает.
Для круглосуточной работы см. «Автозапуск» ниже.

## Шаг 7. Добавьте бота в группу и выдайте права

1. Откройте группу → **Название группы** (сверху) → **Участники** → **Добавить участника** →
   найдите `@my_group_moder_bot` → добавить.
2. В списке участников нажмите на бота → **Назначить администратором** (или «Изменить права»).
3. Обязательно включите право **«Удалять сообщения»** (Delete messages). Остальные права — по желанию.
4. Нажмите **Сохранить**.

Сразу после добавления бот сам напишет в группу приветствие с подсказкой.

> Проверить права можно из консоли: `python manage.py doctor --chat -1001234567890`
> (ID группы — из шага 8). Ожидаемый ответ: `✅ У бота есть право удалять сообщения`.

## Шаг 8. Узнайте ID группы (нужно только для `doctor` и `ALLOWED_CHAT_ID`)

Любой из способов:

* **Из панели бота:** отправьте в группе `/settings` — в панели будет строка `Чат: -100…`.
* **Из логов:** бот пишет `чат=-100…` при удалении сообщения или ошибке.
* **Через бота-подсказку:** перешлите любое сообщение из группы боту [@userinfobot](https://t.me/userinfobot) —
  он покажет `Chat ID`.

У групп ID отрицательный и обычно начинается с `-100`.

## Шаг 9. Включите фильтры

В группе отправьте:

```
/settings
```

Откроется панель (доступна **только администраторам группы**):

```
🛡 Модерация группы
Чат: -1001234567890
Включено фильтров: 3 из 4

✅ вкл — Сообщения от @zaztagbot
✅ вкл — Хэштег #реклама
✅ вкл — Медиа от @zaztagbot
❌ выкл — Медиа от не-админов

[✅ Сообщения от @zaztagbot]
[✅ Хэштег #реклама]
[✅ Медиа от @zaztagbot]
[❌ Медиа от не-админов]
[🔄 Обновить] [♻️ Сбросить]
```

Нажимайте кнопки — изменения применяются сразу и сохраняются в базе. Что означает каждый фильтр:

| Фильтр | Удаляет |
|---|---|
| **Сообщения от @zaztagbot** | любое сообщение этого аккаунта |
| **Хэштег #реклама** | сообщения с этим хэштегом в тексте или подписи к фото |
| **Медиа от @zaztagbot** | фото/видео/GIF/кружки от этого аккаунта |
| **Медиа от не-админов** | фото и видео всех участников, кроме администраторов группы |

## Шаг 10. Проверьте, что модерация работает

1. Отправьте в группу сообщение с текстом `тест #реклама` (с аккаунта, который не админ).
2. Сообщение должно исчезнуть в ту же секунду, а бот может коротко ответить «🗑 Удалено: …».
3. Если сообщение осталось — смотрите таблицу ниже и лог бота.

## Автозапуск (чтобы бот работал всегда)

### Linux (systemd) — рекомендуется для VPS

```bash
sudo nano /etc/systemd/system/moderation-bot.service
```

```ini
[Unit]
Description=Telegram moderation bot
After=network-online.target

[Service]
WorkingDirectory=/opt/moderation_bot
ExecStart=/opt/moderation_bot/.venv/bin/python -m bot
Restart=always
RestartSec=5
User=botuser

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now moderation-bot     # автозапуск + старт
sudo systemctl status moderation-bot           # состояние
sudo journalctl -u moderation-bot -f           # живые логи
```

### Linux/macOS без root (screen или tmux)

```bash
screen -S modbot           # или: tmux new -s modbot
python -m bot
# отключиться, не убивая бота: Ctrl+A, затем D
# вернуться: screen -r modbot
```

### Windows (Планировщик заданий)

1. `Win+R` → `taskschd.msc` → **Создать задачу**.
2. Вкладка **Общие**: имя `Moderation Bot`, галочка «Выполнять с наивысшими правами», «Выполнять
   только при регистрации пользователя».
3. Вкладка **Действия** → Создать: программа —
   `C:\путь\к\moderation_bot\.venv\Scripts\python.exe`, аргументы — `-m bot`,
   рабочая папка — `C:\путь\к\moderation_bot`.
4. Вкладка **Условия**: снять галочку «Запускать только при питании от электросети» (для ноутбуков).

## Если что-то не работает

| Симптом | Причина | Решение |
|---|---|---|
| `❌ Ошибка конфигурации: BOT_TOKEN не задан` | нет `.env` или в нём осталась заглушка | `cp .env.example .env`, вставить токен из шага 1 |
| `Telegram отклонил токен` | токен скопирован не полностью или отозван | проверить токен целиком, при необходимости `/revoke` у @BotFather |
| `❗ У бота установлен вебхук` | раньше бот работал через вебхук, а сейчас нужен long polling | `python manage.py selftest --delete-webhook` |
| `Conflict: terminated by other getUpdates request` | запущено **два** экземпляра бота | остановить лишние: `pkill -f "python -m bot"` (Linux) / закрыть лишние окна |
| Бот удаляет чужие сообщения, но не видит обычные | включён режим приватности | шаг 2: `/setprivacy` → Disable; при необходимости перепригласить бота |
| `Не удалось удалить сообщение …` в логе | у бота нет прав администратора | шаг 7: выдать права с «Удалять сообщения»; проверить `manage.py doctor --chat <ID>` |
| Панель `/settings` не открывается | вы не администратор группы, либо команда отправлена не в группу | отправить в группе с аккаунта-администратора |
| Сообщения от `zaztagbot` остаются | у бота другое @username, или фильтр выключен | уточнить @username в профиле, обновить `TARGET_USERNAME` в `.env`, перезапустить; проверить кнопку в `/settings` |
| `Хэштег #реклама` не ловится | хэштег в сообщении выглядит иначе | `manage.py demo` покажет, что происходит; при необходимости поменять `BANNED_HASHTAG` |
| Бот отвечает «⛔ Команда доступна только администраторам» | команда отправлена не админом | это защита, так и задумано |
| Не запускается: `No module named bot` | команда запущена не из каталога `moderation_bot` | `cd moderation_bot` и снова `python -m bot` (или используйте `make run`) |
| Не запускается: `python: command not found` | не активировано окружение | `source .venv/bin/activate` (Windows: `.venv\Scripts\activate`) |

**Где смотреть логи.** Всё пишется в консоль, где запущен бот. Для systemd — `journalctl -u moderation-bot -f`.
Подробность настраивается переменной `VERBOSE_LOG` в `.env` (поставьте `false`, чтобы не логировать
каждое удаление).

## Шпаргалка команд

Запускать из каталога `moderation_bot` (при активном окружении — `.venv/bin/…` вместо `python`).

| Команда | Что делает |
|---|---|
| `python -m bot` | запустить бота |
| `python manage.py selftest` | проверить готовность (`--offline` — без обращения к Telegram) |
| `python manage.py selftest --delete-webhook` | снять мешающий вебхук |
| `python manage.py demo` | показать, что бот удалит, без Telegram |
| `python manage.py doctor --chat <ID>` | проверить права бота в конкретной группе |
| `python manage.py list` | настройки модерации всех групп из базы |
| `python manage.py set --chat <ID> --flag <флаг> --value on\|off` | включить/выключить фильтр из консоли |
| `pytest` | прогнать тесты |

В Telegram: `/settings` — панель фильтров, `/help` — справка, `/rule` — то же, что `/settings`.

## Куда что сохраняется

* Настройки фильтров — в SQLite-файле `data/moderation.sqlite3` (рядом с ботом), **отдельно для каждой группы**.
* Бэкап: остановите бота и скопируйте файл `data/moderation.sqlite3` (вместе с `-wal` и `-shm`, если есть).
* `.env` в git не попадает (он в `.gitignore`) — токен останется локальным.

Всё получилось? Тогда бот уже удаляет рекламу. Дальше можно ничего не настраивать —
или заглянуть в `README.md` за деталями (лог-чат для аудита, ограничение одной группой и т.д.).
